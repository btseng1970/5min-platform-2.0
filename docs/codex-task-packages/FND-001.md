## 9. Full GA Block（GA-001~015，全文照錄）

| :---- | :---- | :---- | :---- |

| GA-002 | UTC Only / Midnight Crux | 所有 expires_at / accounting / expiry SQL 必須使用 UTC timestamp；禁止 application local timezone 運算。 | UTC lint + TW/JP midnight boundary tests。 |
| GA-003 | No SUPERSEDED Context | Codex task 不得引用標註 SUPERSEDED 之段落。 | docs lint fail。 |
| GA-004 | DB-backed Token Only in Phase 1 | 禁止 Redis/memory TokenSource。 | dependency allowlist + code scan。 |
| GA-005 | DrawReserved-time Result | 抽獎結果於交易中決定，settlement 不改判。 | reward transaction tests。 |
| GA-006 | Idempotency Returns Existing Result | unique violation 需 catch 後回傳既有結果。 | concurrent idempotency test。 |
| GA-007 | QR Code Atomic Enforcement | qr.code 原子狀態轉移為一碼一用唯一執法點。 | QR concurrency + E1 test。 |

**ADR-000 Stack**：TypeScript / Node.js 24 LTS / NestJS / Next.js / PostgreSQL 16 / pg-boss / SQL-first migrations / Kysely。套件管理器：npm workspaces（ADR-000.1，**Accepted，commit 686a925**）。

## 10. Implementation Steps
1. Root workspace config：
   * `package.json`：`"workspaces": ["apps/*", "packages/shared/*"]`（**明確不含** `scripts/dev`；`scripts/dev/` 依 ADR-000.1 第 3 項維持獨立、非 root workspace 成員，其自身 `package.json`/`package-lock.json` 由 FND-000.1 處理，不屬本任務範圍），root `scripts`（`dev:api`/`dev:web`/`dev:admin`/`dev:worker`/`build`/`lint`/`test`，皆透過 `--workspace` 委派），`engines.node`：`">=24 <25"`。
   * **`packageManager`（已核准）**：Dependency-version Human Review 已於 **2026-07-14** 核准確切版本 **`npm@11.9.0`**（理由：`engines.node` 為 `^20.17.0 || >=22.9.0`，完整涵蓋核准 Node 範圍 `>=24 <25`；Node.js 24.14.0 LTS 官方即內建 npm 11.9.0，提供其已整合進官方 Node 24 LTS 發行版之直接證據；維持在 npm major 11，相對其他 npm 11 候選版本不引入 lockfile-major 遷移；npm@12.0.1 因 `engines.node`（`^22.22.2 || ^24.15.0 || >=26.0.0`）未涵蓋完整 `>=24 <25` 範圍而被否決；本決定不基於「本機剛好已安裝該版本」）。root `package.json` 必須含：`"packageManager": "npm@11.9.0"`。root `package-lock.json` 必須以 npm 11.9.0 產生。`packageManager` 欄位**不會**使 npm 自動安裝或切換版本；Corepack 於本架構中維持選用（optional），非強制機制（見 ADR-000.1 第 4 項）。
   * `.nvmrc`：內容為 `24`（單一版本真相來源，FND-000.1 的 CI 步驟會讀取此檔）。
   * `.npmrc`：`engine-strict=true`（使各 workspace 成員與 `scripts/dev/` 的 `engines` 欄位從「警告」變成「安裝時強制失敗」）。
   * `tsconfig.base.json`：共用編譯選項（`strict: true` 等）。
   * ESLint（flat config）+ Prettier 設定，root 共用，`eslint-config-prettier` 停用格式衝突規則。
2. `apps/api`：NestJS skeleton（`main.ts`、`app.module.ts`、`healthz/healthz.controller.ts` 回應 `GET /healthz`），自有 `package.json`（`"engines": { "node": "24.x" }`）、`tsconfig.json`（`extends` root base）。
3. `apps/web`、`apps/admin`：Next.js 預設 App Router 骨架（單一 placeholder 頁面），自有 `package.json`（含 `engines`）、`tsconfig.json`。
4. `apps/worker`：最小 TS entrypoint（啟動後 log 一行、保持存活，無 pg-boss/outbox 邏輯），自有 `package.json`（含 `engines`）、`tsconfig.json`。
5. `packages/shared/{event-envelope,errors,money,time,test-fixtures,api-contract}`：各自 `package.json`（含 `engines`）、`src/index.ts`（空骨架）、`tsconfig.json`；真正的 value object 實作留待 FND-007。
6. 確認所有新增檔案落在 Allowed 清單內；不得觸碰 `.devcontainer/**`、`.github/workflows/ci.yml`、`docker-compose.yml`、`scripts/dev/**`（Node 版本對齊為 FND-000.1 獨立範圍）。

## 11. Acceptance Criteria
* ADR-000 monorepo skeleton 存在：`apps/api`、`apps/web`、`apps/admin`、`apps/worker` 均可各自啟動（process 正常啟動不崩潰）。
* `apps/api` 的 `GET /healthz` 回傳 200。
* npm workspaces 生效：root `npm install` 能一次安裝所有 workspace 成員依賴，`package-lock.json` 為單一 root lockfile。
* Node 版本釘定設定存在（靜態檢查，非行為測試）：`.nvmrc` 內容為 `24`；root `package.json` 之 `engines.node` 為 `>=24 <25`；每個 workspace 成員 `package.json` 含對應 `engines`；root `.npmrc` 含 `engine-strict=true`。實際「非 24.x 版本執行時強制失敗」之行為驗證屬 FND-000.1 範圍（CI/runtime 對齊擁有者），不在本任務 Acceptance Criteria 內；本任務不得為此安裝或呼叫 Node 25。
* root `package.json` 之 `packageManager` 欄位**必須**為 `"npm@11.9.0"`（dependency-version Human Review 於 2026-07-14 核准之確切版本；已驗證與 Node.js 24 LTS 相容，見 §10）；不得為 `latest`、版本範圍，或其他版本字串。此為驗收之阻斷性要求，非選填。
* root `package-lock.json` 必須確認由 npm 11.9.0 產生（而非以其他 npm 版本產生後才回填 `packageManager` 欄位）。
* 未新增 `packages/domain/**`、`packages/infrastructure/**`、`migrations/**` 內容。
* 未觸碰 `.devcontainer/**`、`.github/workflows/ci.yml`、`docker-compose.yml`、`scripts/dev/**`。
* 未安裝 ADR-000/ADR-000.1 allowlist 之外的依賴（GA-013）；未引入 pnpm/yarn。
* **前置條件（已滿足）**：`docs/adr/ADR-000.1.md` 已簽核為 Accepted（commit 686a925）；ADR-000.1 Gate 條款已解除，root `package.json`（workspaces 設定）與 `package-lock.json` 現可於本 task package 自身之 Human Review 通過後 commit。

## 12. Tests Required
* **Smoke**：四個 app 各自啟動不崩潰；`apps/api` 的 `/healthz` 回傳 200（Jest + supertest 或等效輕量 HTTP 檢查）。
* **Lint**：`npm run lint`（ESLint + Prettier）於整個 workspace 乾淨通過。
* **Runtime pinning 靜態驗證**（正向測試，於 Node 24 環境下執行）：
  * 確認 `.nvmrc` 內容為 `24`。
  * 確認 root `package.json` 之 `engines.node` 為 `>=24 <25`。
  * 確認 root `.npmrc` 含 `engine-strict=true`。
  * 確認 build/lint/typecheck/smoke 等既有測試在 Node 24 環境下皆正常執行通過。
* 明確排除於本任務測試範圍：架構/import-boundary lint（FND-002）、DB/migration 測試（FND-003+）、CI guardrail scanners（FND-006）、**wrong-major Node 版本負向執行測試**（例如實際安裝/呼叫 Node 25 觸發 `engine-strict` 失敗）—— 該項行為測試移至 **FND-000.1**，因 CI 與 runtime 對齊由 FND-000.1 擁有；本任務不得安裝或呼叫 Node 25。
